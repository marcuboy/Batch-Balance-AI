Custom ERP / WMS Field Mapping

Your ERP is not on the list — no problem. StockSense needs five types of data. Use this guide to check your export file headers match the expected column names below. You can rename columns in Excel before uploading, or contact your ERP team to export with these exact names.

How to use this: Export your data from your ERP or WMS system as Excel (.xlsx) files. Compare your column headers to the required names below. Rename any that do not match. StockSense will then read them correctly.
📋 MRP / Demand File (required)
FieldRequired column nameWhat it contains
Plant / Site codeCol A (index 0)Single letter site code — G for primary, A for secondary. Or use your own codes and note them.
Vendor codeCol B (index 1)Short supplier reference code e.g. V001
Vendor nameCol C (index 2)Full supplier name e.g. Apex Seating Systems
Part numberCol I (index 8)Your internal part or SKU number
AnalystHeader = AnalystName of the person responsible for this part
Daily demandCols AO onwards (index 38+)One column per day with a date header (YYYY-MM-DD). Each cell = qty demanded that day.
📦 Stock on Hand File (required)
FieldRequired column nameWhat it contains
Warehouse / siteWarehouseWarehouse code. Map your primary warehouse to WH-ALPHA and secondary to WH-BETA in your export file, or use these as-is with the provided dummy datasets.
Part / item numberItemMust match exactly the part numbers in your MRP file
Stock on hand qtyInventory_on_HandCurrent unrestricted stock quantity
📐 Packaging File (optional — enables volume analysis)
FieldRequired column nameWhat it contains
Part numberItem (child)Part number that goes into the packaging
Pack item codePackaging ItemCode of the box, tub or tray used
Qty per boxQuantityHow many parts fit in one packaging unit
Default flagDefault Package DefinitionYes or No — marks the primary packaging type
📏 Dimensions File (optional — required for volume)
FieldRequired column nameWhat it contains
Pack item codePackaging Item (child)Must match codes in Packaging file
LengthLengthExternal box length in centimetres
WidthWidthExternal box width in centimetres

💷 Price File (optional — enables value analysis)
FieldRequired column positionWhat it contains
Part numberColumn A (index 0)Part number matching your MRP file
DescriptionColumn B (index 1)Part description (optional but recommended)
Unit priceColumn C (index 2)Unit cost in GBP (or your local currency)

Obsolete flagColumn E (index 4)900 if obsolete, blank otherwise
Tip: The easiest approach is to export your data as-is, open in Excel, and use Find & Replace on the header row to rename columns to match the names above. This takes about 5 minutes and only needs to be done once — save your reformatted template for future exports.
